*📌 Topics Covered Today*

*1. Hello, World!*

*2. Variables & Types*
Learned about the three basic data types:
• `int` → whole numbers
• `float` → decimal numbers
• `str` → text/strings
Also practiced declaring multiple variables in a single line.

*3. String Formatting*
Used `%d`, `%f`, `%s`, and `%.2f` to format and display values inside strings — the old-school but important way to format output in Python.

*4. Lists*
Created lists, added items using `.append()`, mixed different types in one list, and used a `for` loop + `if/elif/else` to handle each element differently based on its type.

*5. Basic Operators*
Covered arithmetic operators:
• `+`, `-`, `*`, `/` — basic math
• `%` — modulo (remainder)
• `**` — power/exponent
Also saw how `*` and `+` work on strings and lists (repetition & joining).

*6. Basic String Operations (Part 1)*
• `len()` — length of a string
• `.index()` — find position of a character
• `.count()` — count occurrences
• String slicing `[3:7]`
• Reverse a string `[::-1]`

*7. Basic String Operations (Part 2)*
• `.upper()` / `.lower()` — change case
• `.startswith()` / `.endswith()` — check prefix/suffix
• `.split(" ")` — break string into a list of words

*8. Conditions*
Went beyond simple `if/else` and learned:
• `and` — both conditions must be true
• `or` — at least one condition must be true
• `in` — check if a value exists in a list
