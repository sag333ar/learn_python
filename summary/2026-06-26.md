📘 *Today's Python & GitHub Session Summary* (2 Hours)

Today, students learned the basics of Python programming, including:

* Printing output in Python
* Running Python programs
* Declaring integer variables
* Using conditions with `if` and `else`

Apart from Python basics, we also had an in-depth introduction to *Git & GitHub*.

Topics covered:
✅ What is a Version Control System (VCS)
✅ Introduction to Git, GitHub, GitLab, Mercurial, etc.
✅ Difference between Local & Remote Repository
✅ Creating GitHub accounts and repositories
✅ Public vs Private repositories
✅ Basic Git commands:

* git add
* git commit
* git push
* git pull

Students also learned:

* What are branches and why branching is important
* How software teams collaborate
* What is a Pull Request (PR)
* Basics of Code Review process
* Merging changes into the main branch

Practical activities:
💻 Students created GitHub repositories
💻 Added and pushed files to GitHub
💻 Worked with branches and pull requests

Out of 4 students, 3 successfully completed the full exercise. One student faced laptop performance issues. Students are encouraged to bring their own laptops regularly so they can continue their practice smoothly.

🔐 We also covered basic Cybersecurity awareness:

* Checked email breach status using HaveIBeenPwned
* Importance of strong and unique passwords
* Introduction to password managers like:

  * Bitwarden
  * Google Password Manager
  * Apple Passwords / Passkeys

Overall, it was a highly practical and hands-on session focused on both programming fundamentals and real-world developer workflows. 🚀
