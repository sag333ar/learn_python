*📌 Topics Covered*

*1. Defining a Function*
Learned the `def` keyword, function naming, and how the indented block underneath becomes the function body.

*2. Parameters*
Functions can take parameters without specifying a type — Python treats them as `Any`, so a function written for strings will happily accept numbers too (they just get printed/concatenated, not added).

*3. Returning a Value*
Used `return` to send a value back to the caller, e.g. a function that sums two numbers.

*4. Calling a Function*
Called functions with different argument types — strings, numbers — and observed how Python handles each without throwing type errors.
